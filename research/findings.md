# SafeCampus - Research Findings
## Key Findings
1. **80%** did not know the correct emergency number → Add "Call Security" button
2. **100%** said speed matters → 3-tap QuickTap flow
3. **60%** worried about privacy → Anonymity toggle
4. **80%** wanted confirmation → Report ID + status tracking
5. **100%** said long forms stop reporting → Short optional form
6. **60%** concerned about location accuracy → Auto-location + edit
