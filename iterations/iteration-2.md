# SafeCampus - Iteration 2 (After Usability Testing)
## Change 1 - Location Editing
**Problem:** Users couldn't easily fix inaccurate GPS location.
**Change:** Added clear "Edit location" button.
## Change 2 - Status Visibility
**Problem:** Icon-only status badge was unclear.
**Change:** Replaced with colored badge + text label.
## Change 3 - QuickTap Wording
**Problem:** Confirmation text confused users.
**Change:** Changed to "A security team will be notified. Still submit?"
## Change 4 - Call Button on Success
**Problem:** After submitting, users wanted to also call.
**Change:** Added "Call Security" button to success screen.
