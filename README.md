# Campus Emergency Reporting Mobile App

## 📌 Project Overview
This project focuses on designing a user-centered mobile application prototype to enable students, faculty, and campus visitors to report emergencies and safety incidents rapidly and accurately. Designed as part of the Human-Computer Interaction (HCI) coursework, this project emphasizes rapid action, location accuracy, minimal interaction overhead, and stress-tolerant interface design.

## 🎯 Problem Statement
In high-stress campus emergency situations, traditional reporting via phone calls often leads to delayed response times due to panicking users failing to communicate exact locations or critical incident details clearly. Standard mobile interfaces are often too complex for users experiencing cognitive overload during acute stress.

## 🚀 Objectives
- Enable users to trigger an emergency alert or contact campus security within 2 touch actions.
- Provide automatic and manual real-time location sharing across campus grounds.
- Simplify incident category selection to reduce cognitive friction under stress.
- Provide clear visual and haptic status feedback during active emergencies.

## 📱 Key Features
1. **One-Tap SOS Button:** Instant panic trigger that routes location to security.
2. **Categorized Incident Reporting:** Rapid options for Fire, Medical, Security, and Facility Hazards.
3. **Interactive Campus Location Pinning:** GPS auto-detect with manual building/floor selection.
4. **Real-time Incident Status Tracking:** Live updates on dispatch status and responder arrival.
5. **Emergency Contacts & Safety Guides:** Quick access to campus security and basic first-aid procedures.
