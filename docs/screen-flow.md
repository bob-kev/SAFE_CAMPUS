## Design Rationale
- **Persistent "Call Security" button** accessible from all screens (Screen 6)
- **QuickTap flow** minimizes taps during emergencies
- **Success screen** provides reassurance with Report ID
- **Status tracking** keeps users informed
- **Onboarding** guides first-time users
