# SafeCampus - User Scenarios
## Scenario 1 - QuickTap (Fastest Path)
Home → "Report Incident" → tap "Fire" → location auto-filled → "SUBMIT" → Success.
**Result:** Submitted in 3 taps.
## Scenario 2 - Detailed Guided Report
Home → "Report Incident" → tap "Suspicious Activity" → edit location → fill details → "Submit" → Success.
## Scenario 3 - Manage & Follow Up
Home → "My Reports" → tap a past report → view status timeline → "Call Security".
## Scenario 4 - Help Resources
Home → "Safety Resources" → read emergency numbers → "Call Security".
