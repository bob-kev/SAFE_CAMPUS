# SafeCampus - Task Flows & User Journey
## Core Task Flow: Report an Incident (3-Tap Path)
1. **[Home]** → User taps "Report Incident"
2. **[Emergency Type]** → User selects a category
3. **[Report Confirm]** → Location auto-shown + quick description → "Submit"
4. **[Success Screen]** → Confirmation + Report ID
## User Journey
1. Maya sees smoke near the parking lot at night.
2. She opens SafeCampus and taps "Report Incident."
3. She taps "Fire."
4. Location is auto-captured; she adds "smoke near Lot B."
5. She reviews and taps "Submit."
6. Success screen shows Report ID #4821.
## Alternative Flows
- **QuickTap:** Emergency type → Submit in 2 taps.
- **Call Security:** Persistent button on every screen.
- **Detailed report:** Type → Details form → Location → Submit.
