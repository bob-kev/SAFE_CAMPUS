# SafeCampus - Usability Test Plan
## Goals
Test whether 5 users can report a mock incident quickly and error-free.
## Test Tasks
- **T1.** Report "Fire" near a specific location
- **T2.** Call security from home screen
- **T3.** Report incident and fix wrong location
- **T4.** Find previous report and check status
- **T5.** Find emergency contact numbers
## Metrics
- Task completion (success/fail)
- Time on task
- Number of taps
- Errors made
- User satisfaction (1-5)
